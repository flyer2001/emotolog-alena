# Страница /metod — план (SEO)

**Цель:** ранжироваться по «что такое эмотология», «метод эмотологии»,
«эмотолог что это», «метод Александра Шахова», «эмоционально-рефлексивная
терапия».

**Baseline (perplexity, топ-3 по «что такое эмотология метод Шахова»):**
1. `blog.talon.by/.../zachem-nam-nuzhen-emotolog` — интервью, ~1200 слов,
   H1 + H2 без явной структуры, нет FAQ-разметки, нет Schema.
2. `npr.by/emotolog-alla-smolikova-...` — Q&A формат, ~1800 слов, H2 по
   вопросам, аналогия «эмотолог = врач узкого профиля».
3. `ashahov.com/ae_box` — лендинг курса, не инфо-страница, ~800 слов
   текста + CTA, оптимизирован под «обучение эмотологии».

Вывод: у топа слабая on-page SEO (нет Schema, нет чёткой H-иерархии).
Можно обойти чистой структурой + FAQPage JSON-LD + внутренней перелинковкой.

**Объём:** 1500-2000 слов (хватит, топ не длиннее).

**H-структура:**
- H1: Что такое эмотология — метод работы с эмоциями через тело
- H2: Эмотология: определение и суть метода
- H2: Кто такой эмотолог и чем занимается
- H2: Александр Шахов — автор метода эмотологии
- H2: Как проходит сессия: этапы работы
  - H3: 1. Определение эмоции
  - H3: 2. Поиск источника в теле
  - H3: 3. Проживание эмоции
  - H3: 4. Инструменты психогигиены
- H2: Чем эмотология отличается от классической психотерапии
- H2: Чем эмотология отличается от телесно-ориентированной терапии
- H2: С какими запросами работают эмотологи
- H2: Границы метода — что эмотолог не делает
- H2: Частые вопросы (FAQ)

**Ключи (density ~1-2%):**
- primary: эмотология (10-15), эмотолог (10-15), метод эмотологии (5-7)
- secondary: Александр Шахов (4-6), эмоционально-рефлексивная терапия (3-5),
  работа с эмоциями (5-7), что такое эмотология (2-3)
- long-tail: как проходит сессия эмотолога, чем эмотолог отличается от
  психолога, этапы метода эмотологии

**Schema.org:** FAQPage JSON-LD (5-7 Q/A), Article nested через mainEntityOfPage.
Person/Business уже наследуются из Layout.

**Внутренние ссылки:**
- `/#pains` — «с какими запросами приходят» (из H2 про запросы)
- `/#how` — «подробнее про этапы на главной» (из H2 про сессию)
- `/#cases` — «реальные примеры» (из H2 про запросы)
- `/#pricing` — CTA внизу «попробовать 15 мин бесплатно»
- `/` — breadcrumb/лого

**Безопасные формулировки (feedback-v1):**
- БЕЗ слов «панические атаки», «эмоциональное переедание», «ПТСР»
- БЕЗ «не разговоры», «не годы терапии», «не детство» → позитив
- Шахов — нейтрально: «психолог, кандидат психологических наук, автор метода»,
  без «гуру», «ТОП-5» (хотя на главной есть — на /metod НЕ дублируем, менее
  доверительно для SEO-страницы)
- Отличие от терапии — нейтральное сравнение, без обесценивания
- Границы: явный disclaimer «не ставит диагнозов, не заменяет психотерапию»

**CTA:** мягкий — ссылка на «15 мин бесплатно» внизу, не агрессивный.

**noindex:** унаследуется из Layout (вся площадка draft).

**Файл:** `site/src/pages/metod.astro`, использует `Layout`, inline контент
(без новых компонентов — одноразовая SEO-страница).
