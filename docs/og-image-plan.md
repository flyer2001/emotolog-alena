# OG-image 1200×630 — план

## Baseline (до правки)
- `og:image` на alena-emotolog.ru = `/alena.jpeg` — вертикаль 720×1280.
- В landscape-превью TG/VK/WhatsApp обрезается ужасно (лицо/низ режется, boop).
- Задача: собственная 1200×630 карточка в брендовой пудре.

## Решение (после research + GPT-5 critique)
- Холст 1200×630, safe-zone 1120×560 (отступы 40 px).
- Композиция: **текст слева ~62%, cutout Алёны справа ~38%**. Один акцент.
- Палитра: фон `#FBEEE4`, текст `#6B3A32`, акцент `#C08574`, decor `#E8B79C`.
- Декор: мягкий персиковый эллипс-подложка за портретом (нежно, не пестро).

## Типографика
- Kicker (Jost SemiBold, 22 px, tracking +8%, caps): `ЭМОТОЛОГ · МЕТОД ШАХОВА`
- Hero (Playfair Display Italic, 68 px, line-height 1.1):
  `Метод работы с эмоциями через тело`
- Accent (Jost Bold, 36 px, цвет `#C08574`):
  `Результат за 1–3 сессии`
- URL (Jost Regular, 20 px, muted): `alena-emotolog.ru`

Высота hero × 2 строки → читается при даунскейле до ~300 px (критерий GPT-5).

## Фото
- Источник: `assets/booklets/alena_cutout.png` (720×1280, прозрачный фон).
- Позиция: правый край, высота = полный холст, ширина auto (~355 px).
- За портретом — светло-персиковый круг Ø 520, центр ~(950, 315).

## Safe-zone
- Текст целиком в x: 60–740, y: 150–520.
- Портрет в x: 800–1180 — на обрезке TG/VK потерять нестрашно.

## БЕЗОПАСНЫЕ формулировки (мед-риск)
НЕТ: «панические атаки», «эмоциональное переедание» (мед.диагнозы).
ДА: «тревога, выгорание, эмоциональное истощение» → но на OG короче — только hero+accent.

## Экспорт
- SVG → rsvg-convert PNG 1200×630 → `convert` → JPEG Q82 <400 KB.
- Деплой: `site/public/og-default.jpg`, Layout.astro ogImage default → `/og-default.jpg`.
- Добавить `og:image:width=1200`, `og:image:height=630`, `og:image:type=image/jpeg`.
