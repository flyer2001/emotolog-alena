**Формат вывода:** PNG 1080×1080 либо векторный SVG/Figma-файл (предпочтительно с редактируемыми слоями).

## Требования к финалу

- **Формат:** PNG 1080×1080 (или SVG/Figma с редактируемыми слоями — предпочтительно)
- **Уровень качества:** как Instagram-психологи с pro-аккаунтами (Вера Азизи, Полина Хэлп)
- **Читаемость:** все тексты читаемы на mobile screen (при отображении ~500 px)
- **Декор:** line-art в углах (пионы/веточки/ботанические outline). НЕ generic ornament, а реальный ботанический line-art
- **Cutout Алёны:** чистый, без артефактов на волосах, тени под фото мягкая
- **Иерархия:** имя > слоган > темы > оффер (от крупного к мелкому)
- **Воздух:** щедрый, не переполнять. Между секциями должно быть 40–60 px минимум

## Что НЕ делать

- Не использовать эмодзи, стоковые gradient'ы, чёрный фон
- Не менять формулировки текстов
- Не добавлять «специалист по эмоциональной поддержке онлайн 24/7» и подобной маркетинговой воды
- Не рисовать медицинские символы (крест, стетоскоп)
- Не использовать сиреневый/голубой/зелёный
- Не показывать цену без «₽»
- Не использовать watercolor если не можете дать pro-качество (лучше line-art)
