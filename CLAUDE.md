## Правила работы

### СТРОГО ЗАПРЕЩЕНО без разрешения

- Удаление файлов (даже draft'ы могут понадобиться)
- Массовый рефакторинг текстов (тон/смысл — Алена решает)
- `git add .` / `git add -A` (только по имени)
- Публикация текстов от имени Алены (VK/сайт/whatever)

### ВСЕГДА СПРАШИВАТЬ

- Перед изменением tone of voice / позиционирования
- Перед созданием новых папок в корне
- Перед git push (когда remote появится)

### РАЗРЕШЕНО

- Читать существующие материалы для контекста
- Draft'ить новые тексты (Sergey/Алена review'ят)
- Предлагать структуру / улучшения (с объяснением)
- Искать research в интернете (WebFetch, perplexity)

## Git

Локальный git создан, remote пока НЕТ. Sergey закинет на удалённый
позже. Commit'ы делать чисто, per feature/document.

Commit message format: `<область>: <краткая суть>`
Примеры:
- `content: черновик креатива для VK Ads — тема "выход из зависимых отношений"`
- `meanings: позиционирование v1 — целевая аудитория + tone of voice`
- `research: анализ 3-х конкурентов (эмотологи в VK/Telegram)`
